# kaalang

> We be of one blood, thou and I—man and snake together.
>
> — Rudyard Kipling, [“The Spring Running”][spring-running],
> *The Second Jungle Book*

kaalang is a language for writing executable flows as valid Rust. A diagram is
not a separate architectural sketch: visual semantics and execution share one
validated model. The flow you review is the flow the program runs, making
behavior easier to understand and review.

Work in progress. See the [core model](docs/rfcs/0001-core-model.md),
[visual language](docs/rfcs/0002-visual-model.md), and
[SVG renderer](docs/rfcs/0003-svg-renderer.md).
